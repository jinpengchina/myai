# ailove

ailove 是基于 [Poki](https://github.com/JosssphZhou/poki) 的 iPhone 助手开发者预览版。它使用内置 VPN 连接本机，首次设置采用黑底白字的英文单页清单，支持在任务执行时继续用语音补充指令。

[英文文档和自签安装指南](README.md#build-for-your-iphone) · [隐私说明](PRIVACY.md) · [许可证](LICENSE)

首次启动后，按清单完成内置 VPN、设备配对、语音账号和 UI 自动化，再点 **Start Voice Control** 授权麦克风。设备解锁密码和应用配对码分别按 iOS 提示输入。配对请求到达后，应用才会显示六位配对码。

此版本需要用自己的 Apple 开发团队签名。项目附带独立测试版安装脚本，方便通过 Wi-Fi 从头测试。真机首次设置到成功执行一条 AI 指令的全流程仍待验证。
