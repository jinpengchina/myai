# Security

myai can read and interact with the iPhone screen at your request. Depending on the task and account settings, the app can send screen content to the model service you choose and live microphone audio to your voice service. External connections use a relay address you configure.

## Report a vulnerability

Use **Security → Report a vulnerability** in the myai GitHub repository once private reporting is enabled. Keep vulnerability details out of public issues. Include the affected commit, the steps to reproduce, and the impact. Remove passcodes, credentials, pairing records, and private screen content from reports.

## Supported versions

This developer preview supports security fixes on the latest source branch.
